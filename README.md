# codonMatcher

Before running this application, ensure Flask is installed on your system.

Upon launching the application, you will be directed to the index page, which presents four main functionalities:

1. *Find Possible Combinations:* Input a three-digit codon sequence, and the system will generate all possible combinations of codons corresponding to those three letters.

2. *Find Exact Codon:* Enter the exact sequence of codon letters, and the application will display the amino acid it represents.

3. *Find Codon by Name:* Provide the name of an amino acid, and the system will list the different codons associated with that amino acid.

4. *Amino Acid from mRNA Chain:* Input a lengthy sequence of codons used during protein synthesis. Ensure that the sequence begins with the start codon and ends with a stop codon. The system includes validations to ensure accuracy and reliability during the translation process.
